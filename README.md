# ⛩ SAIDAN

推しグッズをアプリ上に並べて、自分だけの祭壇を作れるサービス。

## 概要

アクスタ・缶バッジ・ブロマイドなどの薄型グッズを画像で読み込み、
アプリ上でレイアウトしてコレクションを管理できます。

## 機能

- 🗂️ グッズ登録 — 画像を読み込んでコレクションに追加
- 🖼️ 祭壇メーカー — グッズを自由に配置してレイアウトを作成
- 🤖 自動レイアウト — AIがグッズをかわいく自動で並べてくれる
- ✨ コレクション管理 — 持っているグッズを一覧で整理
